# URBAN DZ — Demo catalog site

Static HTML/CSS/JS prototype. No build tools, backend, payment integration, or paid services required.

## Preview locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository named `urban-dz-demo`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the deployment URL shown in Settings → Pages.

## Before showing to a real client
- This is a fictional portfolio/demo brand.
- The product visuals are CSS illustrations, not real inventory photos.
- Replace demo product names, details, photos, prices, sizes, location, and policies with verified client information.
- Configure `WHATSAPP_NUMBER` in `script.js` using the official shop number in international format (digits only).
- Never claim a real product is available unless the shop confirms it.
- Google Fonts are loaded from the web; system fallbacks are provided.
